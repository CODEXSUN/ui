# Agent Instructions

Before starting work, read [Central Governance](../../mcp-governance/docs/governance.md). Follow its rules and use its index to find the guides needed for your task.

- Work on one authorized step at a time.
- Keep changes within this area's responsibility.
- Preserve other people's work.
- Add only what the task needs.
- Check your work and report the result briefly.

These instructions apply to this folder and its subfolders.

For a standalone repository, keep this file at its root and update the governance link to the team's agreed location. If the link is unavailable, report it before implementation.

This is a development instruction link, not a runtime MCP connection. Follow higher-priority instructions and explicit user direction.
