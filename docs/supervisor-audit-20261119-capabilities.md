## Public contract

- @workspace/ui/blocks/assistant-sidecar exports AssistantSidecar, AssistantChatPanel and their public types. MainLayout adds optional assistant: {url,name,logoSrc,description?}. Product-specific branding/trusted URL composition is supplied by the separately published SDK0.1.7 (ede6b4e4effcb84f5838223f67d7b0aba64a1811), never imported into shared UI.
- The iframe drawer is optional/nonmodal, without an overlay, and host controls remain usable. Closing returns focus to its launcher. Iframe URLs accept only http(s)/relative targets with no URL credentials; configured origin trust, CSP, auth/session and grants remain SDK/host responsibilities. Iframe load is document loading, not proof of authenticated health. Exact cross-origin Escape behavior belongs to the embedded service; the visible Close control is tested.
- MainLayout lazy-loads assistant code only when configured, with a stable-sized logo fallback. Apps with no assistant opt-in do not load the chat module. Existing Sheet overlay behavior stays default true; only the sidecar opts out.
- AssistantChatPanel receives messages, busy/error, history/settings slots and onNew/onSend/onStop/onReview callbacks. onSend(text, readonly File[]) returns Promise<boolean>: true confirms acceptance and clears draft/selections; false/rejection preserves them. It never runs a model, stores credentials, authorizes records or silently retries. Hosts must settle cancelled sends, reconcile uncertain outcomes, and key/remount panels when actor/tenant/conversation identity changes. Source labels carry no authority.
- Voice begins only on user action, creates a reviewable draft and never auto-sends. Late speech events after New/unmount are ignored. Live microphone/recognition accuracy and OS permission prompts were not tested; deterministic API substitution and unsupported-browser fallback were tested. Browser speech service disclosure remains visible.
- @workspace/ui/blocks/attachment-list exports AttachmentList, AttachmentListProps and SavedAttachment (also root exports). Rows carry id/name/sizeBytes/mediaType/revision/canDownload/canDelete, not public file URLs. Async callbacks receive copied snapshots; delete confirms the reviewed revision and rechecks current hint. resourceKey changes reset confirmation/action UI. Host still clears stale rows/reads, authorizes every operation, checks revisions and owns content transport/storage/retention.
- Existing FileUploadProps retains REQUIRED onUpload, so generated Pick<FileUploadProps, onUpload/onFilesChange/disabled> normal adapters keep compiling. New FileSelectionProps requires selectionOnly:true and makes persistence callback optional; FileUpload accepts either type. compact is visual only. Selection-only emits queued local File objects labelled Selected locally, never calls storage or invents saved IDs. Normal upload defaults/progress/validation remain intact; servers independently validate content and access.
